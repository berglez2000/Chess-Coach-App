# Chess Coach App Future Ideas

## Own moves on the game review board
For example if we see a tactical mistake we could edit our chess board. Right now we are unable to move the pieces on the board. We should allow only to make legal moves (now allowing pawn to move 3 squares up)
We should also have a button that will return us to the initial position


## Custom puzzles from My games
After Game Review we can have a button Puzzles from the game. After we click this we will see a position on the board where we made a mistake from the game.
We can also create a few more moves after our tactical mistake

Example:
- We blundered a knight fork (1 move)
- We could've chased a bishop (we make a move, stockfish makes also a move, we make a move, stockfish makes a move) - sequences of moves


## Learning section
Whole new page. When we navigate to the page we could see a list of learning material. For example we could have a whole book in this section with practices.

Example:
- We navigate to /learning page or something like that
- We see a list of learning materials
- We click on one learning material for example 1001 Chess Exercises for beginners
- We can see a list of all chapters from that book (Mate in 1, Mate in 2, Find Missing Piece)
- We would solve puzzles there by chapters and track our progress
